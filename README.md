# 糖糖笔记

使用 HTML、CSS 和原生 JavaScript 编写的双栏笔记软件。左边是笔记列表，右边是标题和正文编辑区。

支持新增、编辑、切换、标题和正文搜索、删除确认、自动保存、字数统计及窄屏布局。内容保存在当前浏览器的 localStorage 中，清除浏览器站点数据会清除笔记，暂无云端同步。

## 使用

在本目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，浏览器访问 http://127.0.0.1:8765 。也可直接打开 index.html；推荐通过本地服务使用，以保持稳定的浏览器存储来源。

## 测试

运行 `node --test test.cjs`。自动化测试使用隔离的 DOM 与存储替身，验证新增、编辑、切换、搜索、字数、刷新恢复、删除取消、删除确认、空列表、纯文本处理和存储异常；不写入真实浏览器数据。

另已通过真实浏览器操作验证新增、编辑、切换、正文搜索、搜索空结果、刷新恢复及删除确认弹窗。
